# Source assets

The original downloads the game's art was imported from. Godot ignores this folder (`.gdignore`),
so nothing here ends up in the exported game. `tools/import_bosses.py` reads the boss files from here.

- `0x72_DungeonTilesetII_v1.7.zip`: 0x72, "16x16 DungeonTileset II" (CC0), https://0x72.itch.io/dungeontileset-ii
- `Undead executioner.zip`: Kronovi, https://darkpixel-kronovi.itch.io/undead-executioner
- `Necromancer_creativekind-Sheet.png`: CreativeKind, https://creativekind.itch.io/necromancer-free
